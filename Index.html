FAQ

 

Windows SmartScreen warns me. Is that normal?

New or unsigned apps can trigger it. Check the SHA-256 under the download, then choose “More info” and “Run anyway”.

How do I check my download?

Run Get-FileHash .\file-name in PowerShell and compare it with the hash on the release.

How do I build it myself?

Clone the repo, run dotnet restore then dotnet build .\WinUI-App.slnx, or press F5 in Visual Studio 2022.
